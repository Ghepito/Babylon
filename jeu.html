        Comment jouer

        Cliquer sur un élément (lac, buisson, arbre, bois mort, prairie, galets, silex, feu, abri) : les actions possibles à cet endroit.
        Cliquer sur Arok : ce qu'il peut faire sur place (boire, manger, expérimenter…).
        Cliquer au sol : y aller. Les actions « 🚶 » le font marcher jusqu'au bon endroit.
        Glisser : tourner autour · molette : zoom · ZQSD : déplacer la vue · AE : pivoter
        Espace pause · F suivre Arok · I IA autonome · Échap fermer
        Le temps passe aussi pendant la marche. À ×1, une minute de jeu par seconde.
